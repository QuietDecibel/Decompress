ESP32, ESP32-S2 and ESP32-S3 camera boards — any board, as long as it runs one of the firmwares listed at the bottom of this page. What Decompress does for them:
  • Recognises the firmware (Espressif CameraWebServer, Tasmota webcam, ESPHome and other MJPEG firmware, RTSP firmware) and finds the stream by itself.
  • Shows the camera's own settings below: resolution, JPEG quality, exposure, white balance, mirror/flip, flash LED. Changes go straight to the camera.
  • One-click presets that tune the camera for pose tracking. Changing the resolution reconnects the live view cleanly.
  • Measures each live view's real frame rate (MJPEG streams don't report one), so recordings keep correct timing.
  • The Discover cameras scan also recognises ESP32 boards now. Logins, if you set one, are kept in the OS credential store.

Flashing a board with CameraWebServer

  1. Install the Arduino IDE, then add esp32 by Espressif Systems in the Boards Manager.
  2. Open File → Examples → ESP32 → Camera → CameraWebServer. In board_config.h, enable your board from the table above. Type your Wi-Fi name and password in the sketch.
  3. Tools: pick your board (e.g. AI Thinker ESP32-CAM or ESP32S3 Dev Module), set PSRAM to enabled (OPI PSRAM on most S3 camera boards) and Partition Scheme to Huge APP.
  4. Upload. The Serial Monitor (115200 baud) prints the camera's address. Enter it above, or press Find ESP32 cameras.
  5. Use a solid 5 V / 2 A supply: weak USB power is the most common cause of resets and dropped streams.

The stock stream serves one viewer at a time, so close the camera's own web page while Decompress is showing it. Its stream is plain HTTP: keep these cameras on your own network.
